# User Directory Table

A React-based user directory application that fetches user data from the ReqRes API, featuring search, sorting, filtering, and pagination.

## Installation

1. Clone the repository or download the project files.

2. Navigate to the project directory:

   ```bash
   cd Frontend-assignment
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and go to `http://localhost:5180` (or the port shown in the terminal).
